openplan GitHub

Terraform for your whole team, on your own infrastructure.

openplan is a self-hosted, open-source alternative to Terraform Cloud. Register a Terraform or OpenTofu module once, and anyone on your team can stand up their own copy from a web UI, with their own variables, their own credentials and a full history of every change.

View on GitHub

Not production ready. openplan is an MVP for local development and evaluation.

Features

Everything a team needs to share Terraform without sharing a laptop.

  • Register templates

    Point openplan at a Git repository and a revision. That becomes a reusable template anyone on the platform can install.

  • Compose stacks

    A stack groups the templates that make up one environment or one service, each with its own configuration.

  • Configure per stack

    Set input variables and attach cloud credentials without editing anyone's Terraform.

  • Plan, apply and destroy

    Run it all from the browser. Runs are durable on Temporal, so a plan or apply survives a restart.

  • Watch runs and read logs

    Every run keeps its init, plan and workspace output, along with its history.

  • Upgrade deliberately

    Moving a stack to a new template revision is an explicit, reviewable step. Nothing drifts silently.

  • Control access per stack

    Grant people a role on the stacks they need, rather than on everything.

  • Sign in with SSO

    openplan signs in through Dex. A corporate IdP, GitHub or LDAP plugs in as a connector.
