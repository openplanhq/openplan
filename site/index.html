Terraform for your whole team, on your own infrastructure.

openplan is a self-hosted, open-source alternative to Terraform Cloud. Register a Terraform or OpenTofu module once, and anyone on your team can stand up their own copy from a web UI, with their own variables, their own credentials and a full history of every change.

Features

Everything a team needs to share Terraform

Without sharing a laptop, a state file or anyone's credentials.

  • acme/terraform-aws-eks @ v1.4.2 hover to register

    Register templates

    Point openplan at a Git repository and a revision. That becomes a reusable template anyone on the platform can install.

  • prod / eks move over the stack

    Compose stacks

    A stack groups the templates that make up one environment or one service, each with its own configuration.

  • node_count = 8 move across to set it

    Configure per stack

    Set input variables and attach cloud credentials without editing anyone's Terraform. Credentials are write-only and injected only while Terraform runs.

  • applied +3 ~1 −0

    Plan, apply and destroy

    Run it all from the browser. Runs are orchestrated durably on Temporal, so a plan or apply survives a restart instead of being lost halfway.

  • Apply complete! Resources: 3 added, 1 changed, 0 destroyed.

    Watch runs and read logs

    Every run keeps its init, plan and workspace output, along with its history.

  • eks v1.3 · v1.4 available hover to upgrade

    Upgrade deliberately

    When a template gets a new revision, moving a stack to it is an explicit, reviewable step. Nothing drifts silently.

  • ana → staging: Operator point at a stack

    Control access per stack

    Grant people a role on the stacks they need, rather than on everything.

  • GitHub · LDAP · OIDC → Dex hover to sign in

    Sign in with SSO

    openplan signs in through Dex. A corporate IdP, GitHub or LDAP plugs in as a Dex connector.

Run it on your own machine

You need Docker and nothing else. Download three files, start it, and open localhost:5173 a minute or two later.

url=https://github.com/openplanhq/openplan/releases/latest/download
curl -LO $url/docker-compose.release.yaml
curl -LO $url/dex.yaml
curl -LO $url/init-databases.sh
docker compose -f docker-compose.release.yaml up -d
