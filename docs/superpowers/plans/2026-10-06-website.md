# openplan website: implementation plan

**Goal:** the one-page website in `site/`, static HTML and CSS styled only by the app's theme.
**Spec:** `docs/superpowers/specs/2026-10-06-website-design.md`

Each task: write the failing guard in `site/src/page.test.ts`, implement, `npm test && npm run build` in `site/`, commit.

1. **Scaffold, guards, top bar, hero.** `site/package.json` (versions as in `web/`), `vite.config.ts` (Tailwind plugin, `server.fs.allow: [".."]`), `src/styles.css` (Tailwind, Geist, `../../web/src/styles/theme.css`), `index.html`, `.gitignore` gains `site/dist/`. Guards: no colour literal, only colours `theme.css` defines, SVGs `aria-hidden` with no text, images with alt, no `<script>`.
2. **Features.** Eight `<li data-feature>` cards, each a drawing over a title and text. Guard: eight features, each drawing with a `primary` accent.
3. **Footer and CI.** The painting in `site/public/footer-train.jpg`, the footer row and credit, and a `site` job in `.github/workflows/ci.yml` mirroring `web`. Guard: the footer's image exists and the credit is present.
4. **Browser check.** At 1280 and 375 wide: layout matches the canvas, no horizontal scroll on a phone, four focus stops with the theme's ring.
