# openplan website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the one-page openplan website in `site/` as static HTML and CSS, styled only by the app's own theme.

**Architecture:** `site/` is a plain Vite project with the Tailwind plugin and no framework. Its one stylesheet imports `web/src/styles/theme.css` read only, so every colour, radius and type step is the app's. The page is `site/index.html`; its drawings are inline SVG coloured with Tailwind's theme-colour utilities. A Vitest file guards the rules the spec sets (no colour literals, accessible drawings and images, every feature drawing accented).

**Tech Stack:** Vite 8, Tailwind CSS 4 (`@tailwindcss/vite`), Vitest 4, `@fontsource-variable/geist` and `@fontsource-variable/geist-mono`, Node 22 in CI.

**Spec:** `docs/superpowers/specs/2026-10-06-website-design.md`

## Global Constraints

- One page: top bar, hero, features, footer. No docs pages, no dark theme, no deploy workflow.
- No JavaScript ships: `site/` has no framework and no `<script>` in `index.html`.
- `web/src/styles/theme.css` is imported as is; nothing in `web/` changes.
- No colour literal anywhere in `site/` (no hex, `rgb(`, `hsl(`, `oklch(`, and no `fill`/`stroke` attribute other than `none` or `currentColor`).
- Drawings: inline SVG, 240 × 140 (hero 520 × 230, viewBox `0 50 520 230`), strokes 1.5 with round caps and joins, tones `stroke-muted-foreground` (the subject), `stroke-separator` (secondary and dashed), `stroke-dashed-border` (connectors), `fill-card` behind shapes, and a `primary` accent in every feature drawing.
- Every `<svg>` is `aria-hidden="true"` and holds no `<text>`; every `<img>` has non-empty `alt`.
- Copy is sentence case, no exclamation marks; status is an icon and a word, never a coloured dot.
- Package versions match `web/package.json`: `vite ^8.1.3`, `tailwindcss ^4.3.3`, `@tailwindcss/vite ^4.3.3`, `vitest ^4.1.10`, fontsource packages `^5.3.0`.

## Review Focus

1. **A phone, 375px wide.** The hero's two columns and the feature grid stack into one column with no horizontal scroll. Checked in Task 4 by screenshot and by `scrollWidth`.
2. **A change to `web/src/styles/theme.css`.** A renamed or removed token silently drops a utility (Tailwind ignores unknown classes), and a drawing loses its stroke. Task 1's guard pins that every theme colour the page uses exists in `theme.css`.
3. **The painting fails to load.** The band keeps its height and shows the canvas ground with its alt text. Task 3 sets the band's background and fixed height.
4. **Keyboard users.** Every link shows the theme's focus ring. No element in the page suppresses it; Task 4 checks by tabbing through.
5. **The painting's licence.** The build includes the image, but the spec's open question stands: it is not deployed publicly until its credit and licence are known. Called out in the PR description in Task 4.

- [ ] **Step 1: Write the failing test**

`site/src/page.test.ts`:

```ts
import { readFileSync } from "node:fs";
import { dirname, join } from "node:path";
import { fileURLToPath } from "node:url";
import { describe, expect, it } from "vitest";

const SITE = join(dirname(fileURLToPath(import.meta.url)), "..");
const read = (path: string) => readFileSync(join(SITE, path), "utf8");

const HTML = read("index.html");
const CSS = read("src/styles.css");
const THEME = read("../web/src/styles/theme.css");

describe("site/index.html", () => {
  it("holds no colour literal", () => {
    for (const source of [HTML, CSS]) {
      expect(source).not.toMatch(/#[0-9a-f]{3,8}\b/i);
      expect(source).not.toMatch(/\b(?:rgba?|hsla?|oklch)\(/i);
    }
    const paint = [...HTML.matchAll(/\b(?:fill|stroke)="([^"]*)"/g)].map((m) => m[1]);
    expect(paint.filter((value) => value !== "none" && value !== "currentColor")).toEqual([]);
  });

  it("uses only theme colours that theme.css defines", () => {
    const used = new Set(
      [...HTML.matchAll(/\b(?:bg|text|border|fill|stroke)-([a-z]+(?:-[a-z]+)*)\b/g)]
        .map((m) => m[1])
        .filter((name) => !/^(?:none|sm|lg|xl|base|meta|row-title|page-title|panel-title|t|b|l|r|x|y|width|dasharray|linecap|linejoin)$/.test(name))
    );
    const defined = new Set([...THEME.matchAll(/--color-([a-z-]+):/g)].map((m) => m[1]));
    expect([...used].filter((name) => !defined.has(name))).toEqual([]);
  });

  it("hides every drawing from assistive technology and puts no words in one", () => {
    const svgs = [...HTML.matchAll(/<svg\b[^>]*>/g)].map((m) => m[0]);
    expect(svgs.length).toBeGreaterThan(0);
    expect(svgs.filter((tag) => !tag.includes('aria-hidden="true"'))).toEqual([]);
    expect(HTML).not.toMatch(/<text\b/);
  });

  it("gives every image alternative text", () => {
    const imgs = [...HTML.matchAll(/<img\b[^>]*>/g)].map((m) => m[0]);
    expect(imgs.filter((tag) => !/\balt="[^"]+"/.test(tag))).toEqual([]);
  });

  it("ships no JavaScript", () => {
    expect(HTML).not.toMatch(/<script\b/);
  });
});
```

The second test reads class names shaped like `bg-x`, `text-x`, `border-x`, `fill-x` and `stroke-x` and checks each colour name exists in `theme.css`. The filter drops the non-colour utilities the page uses with the same prefixes (`text-sm`, `text-meta`, `border-t`, `fill-none` and the like). If a new non-colour utility trips it, add its name to that filter, not to the page.
